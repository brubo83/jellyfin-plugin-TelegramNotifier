Bot e canale Telegram

Un solo bot e una sola chat (canale, gruppo o chat privata) per tutte le notifiche. In un canale il bot deve essere amministratore.
Il token fornito da @BotFather (es. 123456:ABC-DEF...). Guida: github.com/brubo83/jellyfin-plugin-TelegramNotifier
Es. -1001234567890 per un canale/gruppo, oppure @nomecanale per un canale pubblico.
Solo per i gruppi con argomenti (forum).

Quali notifiche inviare

Clicca il nome di un utente per attivare/disattivare tutta la colonna, il nome di una notifica per tutta la riga, il nome di un gruppo per tutto il gruppo. Le notifiche che riguardano un utente (riproduzioni, sessioni, accessi...) si attivano per utente; quelle del server (aggiunte in libreria, plugin, attività...) si attivano nella colonna Server.

Testo dei messaggi

Segnaposto disponibili
Formato HTML di Telegram (<b>, <i>, <a href>...). I valori dei segnaposto vengono già protetti.

Opzioni

Es. https://jellyfin.miodominio.it. Usato solo nel segnaposto {server.Url}.
Di norma lascialo vuoto: le immagini vengono lette direttamente dal disco o dall'indirizzo locale di Jellyfin, quindi funzionano anche dietro reverse proxy. Serve solo come ultima alternativa (es. http://127.0.0.1:8096).
